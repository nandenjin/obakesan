# Art-Net インターフェース

**Art-Net** インターフェースを使用すると、ネットワーク（有線 LAN または Wi-Fi）経由で DMX 照明データの送受信を行うことができます。

## 入力 (Receiver)

**入力 (Input)** として設定すると、照明コンソールや他のソフトウェアから送信される Art-Net データを受信します。

### 設定項目

| 項目          | 説明                                                                                                                    |
| :------------ | :---------------------------------------------------------------------------------------------------------------------- |
| **Net**       | 上位のネットワークアドレスグループ (0-127)。通常は `0` です。                                                           |
| **Subnet**    | サブグループアドレス (0-15)。通常は `0` です。                                                                          |
| **Universe**  | 具体的な DMX ユニバース (0-15)。                                                                                        |
| **Bind Host** | リッスンするネットワークアダプタの IP アドレスです。すべてのインターフェースでリッスンするには `0.0.0.0` を使用します。 |

送信側（コンソールなど）の Net、Subnet、Universe の設定と一致させてください。

## 出力 (Transmitter)

**出力 (Output)** として設定すると、他の Art-Net ノードやビジュアライザーに対して DMX データを送信します。

### 設定項目

| 項目            | 説明                                                                                                |
| :-------------- | :-------------------------------------------------------------------------------------------------- |
| **Target Host** | 送信先の IP アドレスです。ブロードキャスト（全員に送信）する場合は `255.255.255.255` を使用します。 |
| **Target Port** | ネットワークポートです。Art-Net の標準 UDP ポートは `6454` です。                                   |
| **Net**         | 送信先の Net アドレス (0-127)。                                                                     |
| **Subnet**      | 送信先の Subnet アドレス (0-15)。                                                                   |
| **Universe**    | 送信先の Universe アドレス (0-15)。                                                                 |
| **FPS**         | フレームレート (Frames Per Second)。DMX パケットを送信する頻度を制御します。                        |

## 仕様

Obakesan は Art-Net 4 プロトコル仕様に準拠しています。

- **通信方式**: UDP over Ethernet/Wi-Fi
- **デフォルトポート**: 6454
- **アドレッシング**: 15 ビットアドレス空間 (Net + Subnet + Universe)

# 信号ジェネレータ インターフェース

**信号ジェネレータ** インターフェースは、数学的な波形を使用してDMX照明データを生成します。これは、照明セットアップのテスト、エフェクトの作成、または外部の照明コンソールを必要とせずにDMX制御を実演するのに便利です。

## 入力（信号ジェネレータ）

**信号ジェネレータ** 入力として設定すると、選択した波形と周波数パラメータに基づいて連続的なDMXデータを生成します。

### 設定

| 設定       | 説明                                                                 |
| :--------- | :------------------------------------------------------------------- |
| **波形**   | 生成する波形のタイプ：正弦波、矩形波、またはのこぎり波。             |
| **周波数** | 波形が繰り返される速さ（ヘルツ単位）。範囲：0.1〜100 Hz。            |

### 波形タイプ

#### 正弦波（サイン波）
0から255の間を滑らかに連続的に振動します。穏やかで流れるような照明トランジションを作成します。各チャンネルには若干の位相オフセットがあり、全512チャンネルに「扇状」の効果を生み出します。

**数式**: `value = floor(((sin((t·f + i/512)·2π) + 1) / 2) · 255)`
- `t` = 経過時間（秒）
- `f` = 周波数（Hz）
- `i` = チャンネルインデックス（0-511）

**使用例**:
- スムーズなフェード効果
- 呼吸するようなライト
- 穏やかなカラートランジション

#### 矩形波（スクエア波）
0と255を交互に切り替わる二値信号。鋭いオン/オフトランジションを作成します。各チャンネルには若干の位相オフセットがあり、全512チャンネルに「扇状」の効果を生み出します。

**数式**: `value = (t·f + i/512) % 1 < 0.5 ? 0 : 255`
- `t` = 経過時間（秒）
- `f` = 周波数（Hz）
- `i` = チャンネルインデックス（0-511）

**使用例**:
- ストロボ効果
- オン/オフ切り替え
- 鋭いカラーチェンジ

#### のこぎり波
0から255への直線的なランプで、その後リセットされます。上昇フェードの後、瞬時にリセットされます。各チャンネルには若干の位相オフセットがあり、全512チャンネルに「扇状」の効果を生み出します。

**数式**: `value = floor(((t·f + i/512) % 1) · 255)`
- `t` = 経過時間（秒）
- `f` = 周波数（Hz）
- `i` = チャンネルインデックス（0-511）

**使用例**:
- ランプ効果
- チェイスシーケンス
- 直線的な調光サイクル

### 周波数制御

周波数パラメータは、1秒あたりに完全な波形サイクルが何回発生するかを制御します：

- **0.1 Hz**: 10秒ごとに1サイクル（非常に遅い）
- **1 Hz**: 1秒ごとに1サイクル（デフォルト）
- **10 Hz**: 1秒ごとに10サイクル（速い）
- **100 Hz**: 1秒ごとに100サイクル（非常に速い）

### 技術的詳細

- **更新レート**: 30 FPS（フレーム毎秒）
- **チャンネルカバレッジ**: 全512個のDMXチャンネル
- **チャンネル扇形効果**: 各チャンネルに段階的な位相オフセット（i/512）があり、チャンネル間で波形パターンを作成
- **値の範囲**: 0-255（標準DMX範囲）
- **位相計算**: 開始からの経過時間とチャンネルオフセットに基づく

## 出力互換性

信号ジェネレータは、任意の出力インターフェースで使用できます：

- **Art-Net出力**: 生成された信号をネットワーク経由で送信
- **FTDI USB DMX出力**: USB DMXインターフェース経由で生成された信号を送信

これにより、信号ジェネレータを使用して実際の照明機器やソフトウェアビジュアライザーを駆動できます。

## 使用例

1. **照明機器のテスト**
   - 1 Hzの正弦波を使用して、スムーズな調光機能を確認
   - ストロボテスト用に矩形波を使用

2. **ビジュアル効果の作成**
   - Art-Net出力と組み合わせて、複数の機器間で同期された効果を作成
   - 異なる周波数を使用して、さまざまなビジュアルダイナミクスを実現

3. **デモンストレーションモード**
   - 外部コントローラーなしでDMX制御機能を紹介
   - トラブルシューティングのために予測可能なパターンを生成

## 注意事項

- 信号ジェネレータは外部DMXソースとは独立して動作します
- Art-Netと信号ジェネレータ入力の切り替えはシームレスです
- チャンネルは段階的な位相オフセット値を受け取り、全チャンネルに波形パターンを作成します
- 扇形効果により、異なるチャンネルが異なるタイミングでピークに達する視覚的ダイナミクスを生み出します

# 信号ジェネレータ インターフェース

::: warning テストツール専用
信号ジェネレータは**テストおよびモック用ツール**として設計されており、デザインや本番環境での使用を目的としていません。外部コントローラーを必要とせずにDMX出力と照明セットアップを検証する簡単な方法を提供します。
:::

**信号ジェネレータ** インターフェースは、0.2 Hz（5秒ごとに1サイクル）の固定周波数で数学的な波形を使用してDMX照明データを生成します。

## 入力（信号ジェネレータ）

**信号ジェネレータ** 入力として設定すると、選択した波形タイプに基づいて連続的なDMXデータを生成します。

### 設定

| 設定     | 説明                                                         |
| :------- | :----------------------------------------------------------- |
| **波形** | 生成する波形のタイプ：正弦波、矩形波、またはのこぎり波。     |

**注意**: 周波数は0.2 Hz（1/5）に固定されており、一貫した予測可能なテストパターンを提供します。

### 波形タイプ

#### 正弦波（サイン波）
0から255の間を滑らかに連続的に振動します。穏やかで流れるような照明トランジションを作成します。各チャンネルには若干の位相オフセットがあり、全512チャンネルに「扇状」の効果を生み出します。

**数式**: `value = floor(((sin((t·0.2 + i/512)·2π) + 1) / 2) · 255)`
- `t` = 経過時間（秒）
- 周波数 = 0.2 Hz（固定）
- `i` = チャンネルインデックス（0-511）

**使用例**:
- スムーズな調光機能のテスト
- グラデーション効果の検証
- チャンネル応答の確認

#### 矩形波（スクエア波）
0と255を交互に切り替わる二値信号。鋭いオン/オフトランジションを作成します。各チャンネルには若干の位相オフセットがあり、全512チャンネルに「扇状」の効果を生み出します。

**数式**: `value = (t·0.2 + i/512) % 1 < 0.5 ? 0 : 255`
- `t` = 経過時間（秒）
- 周波数 = 0.2 Hz（固定）
- `i` = チャンネルインデックス（0-511）

**使用例**:
- ストロボ効果のテスト
- オン/オフ切り替えの検証
- バイナリトランジションの確認

#### のこぎり波
0から255への直線的なランプで、その後リセットされます。上昇フェードの後、瞬時にリセットされます。各チャンネルには若干の位相オフセットがあり、全512チャンネルに「扇状」の効果を生み出します。

**数式**: `value = floor(((t·0.2 + i/512) % 1) · 255)`
- `t` = 経過時間（秒）
- 周波数 = 0.2 Hz（固定）
- `i` = チャンネルインデックス（0-511）

**使用例**:
- ランプ効果のテスト
- チェイスシーケンスの検証
- 直線的なフェードの確認

## 技術的詳細

- **更新レート**: 30 FPS（フレーム毎秒）
- **固定周波数**: 0.2 Hz（5秒ごとに1サイクル）
- **チャンネルカバレッジ**: 全512個のDMXチャンネル
- **チャンネル扇形効果**: 各チャンネルに段階的な位相オフセット（i/512）があり、チャンネル間で波形パターンを作成
- **値の範囲**: 0-255（標準DMX範囲）
- **位相計算**: 開始からの経過時間とチャンネルオフセットに基づく

## 出力互換性

信号ジェネレータは、任意の出力インターフェースで使用できます：

- **Art-Net出力**: 生成されたテスト信号をネットワーク経由で送信
- **FTDI USB DMX出力**: USB DMXインターフェース経由で生成されたテスト信号を送信

これにより、信号ジェネレータを使用して実際の照明機器やソフトウェアビジュアライザーが正しく動作しているか検証できます。

## 使用例

1. **照明機器のテスト**
   - 正弦波を使用してスムーズな調光機能を確認
   - 矩形波でオン/オフ応答をテスト
   - のこぎり波でフェード動作を確認

2. **DMX出力の検証**
   - Art-Net送信をテストして適切な接続を確認
   - USB DMXインターフェースが正しく機能しているか検証
   - 全512チャンネルが送信されているか確認

3. **トラブルシューティング**
   - デバッグ用に予測可能で一貫したパターンを生成
   - 問題が制御ソフトウェアか機器にあるかを特定
   - 外部コントローラーなしでDMX信号の整合性を確認

## 注意事項

- 信号ジェネレータは**テストツール**であり、創造的な照明デザイン用ではありません
- 周波数は0.2 Hz（5秒サイクル）に固定されており、一貫した予測可能な動作を提供します
- 信号ジェネレータは外部DMXソースとは独立して動作します
- Art-Netと信号ジェネレータ入力の切り替えはシームレスです
- チャンネルは段階的な位相オフセット値を受け取り、全チャンネルに波形パターンを作成します
- 扇形効果により、異なるチャンネルが異なるタイミングでピークに達する視覚的ダイナミクスを生み出します

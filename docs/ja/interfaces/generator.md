# ジェネレーター

ジェネレーターインターフェースは、テスト用の DMX 照明データを生成します。外部コントローラーを必要とせずに、DMX 出力と照明のセットアップを検証する簡単な方法を提供します。

## 入力（ジェネレーター）

選択された波形タイプに基づいて DMX データを生成します。

### 設定

| 設定           | 説明                                                                                   |
| :------------- | :------------------------------------------------------------------------------------- |
| **波形タイプ** | 生成する波形のタイプ：正弦波（Sine）、矩形波（Square）、またはのこぎり波（Sawtooth）。 |

### 波形タイプ

- 正弦波 (Sine Wave): `value = floor(((sin((t·f + i/512)·2π) + 1) / 2) · 255)`
- 矩形波 (Square Wave): `value = (t·f + i/512) % 1 < 0.5 ? 0 : 255`
- のこぎり波 (Sawtooth Wave): `value = floor(((t·f + i/512) % 1) · 255)`

ただし

- `t` = 経過時間（秒）
- `f` = 周波数 (0.2 Hz 固定)
- `i` = チャンネルインデックス (0-511)

# FTDI インターフェース

**FTDI** インターフェースを使用すると、FTDI チップ（FT232R など）を搭載した汎用 USB-DMX アダプタを使用して DMX512 信号を出力できます。

:::info
シリアルポートの仕様上の制限により、**FTDI インターフェースは出力（Transmitter）のみをサポートしています。**
:::

## 設定

FTDI デバイスを使用するには、コンピュータの USB ポートに接続されていることを確認してください。

### デバイスの選択

アプリケーションは利用可能な FTDI デバイスを自動的にリストアップします。ドロップダウンメニューから使用するデバイスを選択してください。

### 設定項目

| 項目    | 説明                                                                                   |
| :------ | :------------------------------------------------------------------------------------- |
| **FPS** | フレームレート (Frames Per Second)。DMX パケットをデバイスに送信する頻度を制御します。 |

## 対応ハードウェア

**FTDI** チップセットを使用するほとんどの汎用 USB-DMX ケーブルがサポートされています。

- **チップセット**: FT232R, FT232H など
- **プロトコル**: D2XX ドライバ経由の Raw DMX

## 仕様

- **出力規格**: DMX512
- **更新レート**: 設定可能

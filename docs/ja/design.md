# デザインコンセプト

Obakesan は、既製品に頼らず独自のシステムを構築する開発者向けの DMX モニター & コンバーターです。専用ハードウェア不要のスタンドアロンアプリとして、Art-Net と USB DMX の相互変換機能を提供します。データの視認性を重視したミニマルな UI と、既存ワークフローへの統合しやすさを設計の軸としています。

## 設計方針

### シンプルで実用的に

専用ハードウェアや複雑な設定を必要とせず、必要な機能に絞ったスタンドアロンアプリとして動作します。環境を選ばず、すぐに使い始められることを重視しています。

### 既存ワークフローへの統合

Art-Net と USB DMX の相互変換により、既存のツールチェーンに組み込んで使えます。オープンソースなので、必要に応じてカスタマイズも可能です。

## UI デザイン

### データの視認性

DMX チャンネルの値を数値とゲージで表示します。ハイライト表示により、チャンネルの一覧性を下げないデザインを採用しています。

### ミニマルな構成

機能を絞り、必要な要素だけを配置したシンプルなインターフェースを提供します。

### 他ツールとの併用

コンパクトなウィンドウサイズで、他のツールと並べて表示できます。

## ユーザー像

メディアアート作品やインスタレーションでの照明制御、カスタムコントローラーや自動化システムの開発など、既製品に頼らず独自のシステムを構築する開発者の助けになる製品を目指します。

## 名前の由来

「Obakesan」（オバケさん）は、筑波大学の人形劇団 NEU による作品「うしろのともだち」に登場するキャラクターの名から取りました。原作は磯貝美由紀（ジャックポット）によるものです。

A DMX / Art-Net Monitor or Converter App for Stage Designers and Artists.

## 📦️ Get the App

[Visit website](https://nandenjin.github.io/obakesan/)（[日本語](https://nandenjin.github.io/obakesan/ja/)）

## ✨️ Features

- 🌀 **Simple and Lightweight**
- 🧰 Supports **Art-Net, Signal Generator, and FTDI USB DMX (output only)**
- 📊 Built-in **Signal Generator** with sine, square, and sawtooth waveforms
- 🖥️ Works on **Windows, macOS and Linux**
